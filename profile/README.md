## Sobre a APIBrasil

A **APIBrasil** oferece mais de 169 serviços de API em uma única plataforma.
Integre recursos de WhatsApp, consultas de CPF e CNPJ, dados veiculares, geolocalização, rastreamento de encomendas, clima, CEP, feriados e muito mais.
Nossa plataforma foi desenvolvida para empresas e desenvolvedores que precisam de integrações rápidas, seguras e escaláveis.

## Principais API's

### WhatsApp

* API WhatsApp Browser
* API WhatsApp Baileys
* Gerenciamento de instâncias
* Envio e recebimento de mensagens
* Webhooks em tempo real

### CPF e CNPJ

* Consulta de dados de CPF
* Consulta de dados cadastrais
* Consulta SPC e Serasa
* Consulta de CNPJ
* Pesquisa de empresas por CNAE
* Pesquisa de empresas por CEP e UF

### Dados veiculares

* Consulta de multas e restrições
* Consulta de proprietário
* Histórico de proprietários
* Consulta de leilão
* Consulta em base nacional
* Decoder de placa
* Dados completos por placa
* Consulta de FIPE por placa
* Consulta à Tabela FIPE

### Localização e utilidades

* Geolocalização
* Rastreamento de encomendas
* Dados meteorológicos
* Feriados nacionais
* Consulta de DDD
* Consulta de endereço IP
* Consulta de CEP com dados do IBGE
* Cálculo de distância entre CEPs

> Mais de 169 API's profissionais disponíveis em uma única plataforma.

## SDKs oficiais

### PHP

```bash
composer require jhowbhz/apigratis-sdk-php
```

### Node.js e TypeScript

```bash
npm install apigratis-sdk-nodejs
```

### Python

```bash
pip install api-brasil
```

### C# / .NET

```bash
dotnet add package ApiBrasil --version 2.0.3
```

### Java

```bash
mvn dependency:get -Dartifact=br.com.apibrasil:apigratis-sdk-java:1.0.0
```

### Go

```bash
go get github.com/APIBrasil/apigratis-sdk-go
```

### Rust

```bash
cargo add apibrasil
```

### Dart

```bash
dart pub add apigratis_sdk_flutter
```

### Flutter

```bash
flutter pub add apigratis_sdk_flutter
```

### Ruby

```bash
gem install apigratis-sdk-ruby
```

### C++

Repositório:
